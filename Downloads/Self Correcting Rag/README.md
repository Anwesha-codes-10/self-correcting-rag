# Self-Correcting RAG Journey

## Overview

This repository documents my journey of learning and building a Self-Correcting Retrieval-Augmented Generation (RAG) system from scratch.

The goal of this project is to understand how modern RAG systems work and explore techniques for reducing hallucinations in LLM-generated responses through retrieval, relevance filtering, and fact verification.

Rather than building the complete system at once, I am developing it incrementally while learning the underlying concepts and tools.

## Learning Objectives

* Understand embeddings and semantic search
* Learn vector databases such as FAISS
* Build a basic Retrieval-Augmented Generation (RAG) pipeline
* Explore LangChain and LangGraph
* Implement relevance checking for retrieved documents
* Develop a fact-checking component for generated responses
* Evaluate RAG systems using appropriate metrics
